# Напоминалка для автомобиля

Программа хранит даты и показывает, что уже просрочено или закончится в ближайшие 30 дней.

## Как запустить

1. Откройте файл `start_reminder.bat` двойным щелчком.
2. Откроется страница `index.html` в браузере.
3. Выберите тип напоминания, введите день, месяц и год, затем нажмите `Сохранить`.

## Что уже есть

- страховка на машину;
- техосмотр;
- замена масла в двигателе;
- замена масла в коробке;
- замена свечей в двигателе.

Данные сохраняются в браузере на этом компьютере. Для надежности можно нажать `Сохранить копию`, чтобы скачать JSON-файл с резервной копией.

## Автозапуск при включении компьютера

Чтобы программа сама открывалась и проверяла сроки при запуске Windows:

1. Нажмите `Win + R`.
2. Введите `shell:startup` и нажмите Enter.
3. Скопируйте туда ярлык файла `start_reminder.bat`.

После этого при входе в Windows программа откроется и покажет важные сроки.
