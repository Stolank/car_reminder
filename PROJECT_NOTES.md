# Памятка проекта: Напоминалка для автомобиля

## Где находится программа

Папка проекта:

`C:\Users\uolri\OneDrive\Документы\Напоминалка`

Главный файл программы:

`auto_reminder.html`

Файл запуска:

`start_reminder.bat`

Запускать программу нужно двойным щелчком по `start_reminder.bat`. Программа открывается в браузере.

## Что делает программа

Программа хранит напоминания по обслуживанию автомобиля:

- техосмотр;
- страховка;
- масло в двигателе;
- масло в коробке;
- свечи в двигателе.

## Автомобили

Добавлено поле `Машина или госномер`.

Можно нажать `Добавить автомобиль`, после этого машина появляется в выпадающем списке.

Для каждой машины можно вести свои напоминания.

## Быстрые кнопки обслуживания

Есть кнопки:

- `Все`;
- `Техосмотр`;
- `Страховка`;
- `Масло в двигателе`;
- `Масло в коробке`;
- `Свечи`.

При нажатии на кнопку программа показывает в таблице только выбранный вид обслуживания для выбранной машины и подставляет сохраненные данные в форму.

## Расчеты

Техосмотр считается через 1 год от даты прохождения.

Страховка считается через 1 год от даты оформления.

Масло в двигателе считается по пробегу. По умолчанию стоит 5000 км, но можно поставить 4000-7000 км или другое значение.

Масло в коробке считается через 50000 км.

Свечи считаются через 20000 км.

Для масла в двигателе и коробке есть `Рекомендуемая дата`. Она считается так:

`дата прошлой замены + интервал км / среднедневной пробег`

Пример:

- дата прошлой замены масла: 03.05.2025;
- пробег при замене: 164957 км;
- интервал замены: 6000 км;
- текущий пробег: 200616 км;
- среднедневной пробег: 14 км.

Программа показывает:

- следующий пробег замены: 170957 км;
- рекомендуемая дата: 06.07.2026;
- статус: по пробегу превышено на 29659 км.

## Предупреждения

Есть поле `Предупредить за, км`. Можно поставить, например:

- 500 км;
- 1000 км;
- 2000 км.

Для дат программа предупреждает, если осталось 30 дней или меньше.

## Редактирование и удаление

В таблице у каждой записи есть кнопки:

- `Изменить`;
- `Удалить`.

При нажатии `Изменить` программа включает режим редактирования. В этом режиме есть:

- `Сохранить изменения`;
- `Отмена`;
- крестик закрытия.

## Фильтры

Есть фильтры:

- `Все`;
- `Уже пора`;
- `Скоро подойдет`;
- `Еще не скоро`.

## Копии и экспорт

`Сохранить копию` скачивает JSON-файл `car-reminders-backup.json` в папку загрузок браузера.

`Загрузить копию` восстанавливает записи из ранее сохраненного JSON-файла.

`Экспорт в Excel` скачивает CSV-файл `car-reminders.csv`, который можно открыть в Excel.

## Уведомления

Кнопка `Включить уведомления` использует обычные уведомления браузера. Это бесплатно, сервер не нужен.

Важно: программа не работает постоянно в фоне. Она проверяет напоминания, когда открыта.

Чтобы программа открывалась при запуске Windows:

1. Нажать `Win + R`.
2. Ввести `shell:startup`.
3. Скопировать туда ярлык файла `start_reminder.bat`.

После этого при включении компьютера программа будет открываться в браузере и показывать важные напоминания.
