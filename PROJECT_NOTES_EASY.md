# Новая простая версия интерфейса

Главный файл простого интерфейса:

`reminder_easy.html`

Файл запуска:

`start_reminder.bat`

Теперь `start_reminder.bat` открывает именно `reminder_easy.html`.

## Что изменено

- Интерфейс сделан проще для неопытного пользователя.
- Появились крупные шаги:
  1. выбрать автомобиль;
  2. выбрать обслуживание;
  3. заполнить данные.
- Вместо сложной таблицы используются карточки напоминаний.
- Сохранены прежние данные из `localStorage` с ключом `car-reminders-v2`.
- Старый файл `auto_reminder.html` оставлен как запасной.

## Основные функции

- Добавление автомобиля.
- Выбор автомобиля из списка.
- Быстрые кнопки: `Все`, `Техосмотр`, `Страховка`, `Масло в двигателе`, `Масло в коробке`, `Свечи`.
- При выборе услуги существующая запись открывается для изменения.
- Расчет техосмотра и страховки: плюс 1 год.
- Расчет масла и свечей по пробегу.
- Рекомендуемая дата для масла в двигателе и коробке считается по среднедневному пробегу.
- Фильтры: `Все`, `Уже пора`, `Скоро подойдет`, `Еще не скоро`.
- Резервная копия JSON.
- Загрузка резервной копии.
- Экспорт в Excel через CSV.
