## 1. Какая версия обновлена

Основной файл обновлённой программы: `car_reminder.py`.

В проекте также есть браузерные версии. Файл `start_reminder.bat` открывает `reminder_easy.html`, а не программу на Python. Эти версии работают отдельно и не обмениваются напоминаниями автоматически.

Файлы `PROJECT_NOTES.md` и `PROJECT_NOTES_EASY.md` описывают браузерные версии. Их возможности, например расчёт обслуживания по пробегу, не следует приписывать программе `car_reminder.py`.

## 2. Запуск через ярлык

На рабочем столе создан ярлык **«Напоминалка для автомобиля»**. Для запуска достаточно дважды щёлкнуть по нему.

Ярлык запускает `car_reminder.py` через `pythonw.exe` без дополнительного окна командной строки. Рабочая папка ярлыка совпадает с папкой проекта. Значок ярлыка хранится в `car-reminder.ico`.

После изменения кода или оформления нужно закрыть программу и открыть её заново. Создавать новый ярлык при этом не требуется. Если переместить папку проекта или переустановить Python в другое место, пути в ярлыке понадобится обновить.

Для запуска из командной строки в папке проекта используется команда:

```powershell
python car_reminder.py
```

- После выбора записи появляются «Изменить» и значок корзины. Без выбранной записи эти действия скрыты.
- Кнопка «Очистить» убрана: выход из отдельной формы выполняется через «Отмена».
- В таблице сохранены четыре столбца: «Напоминание», «Дата», «Срок», «Заметка».
- Записи располагаются по дате: самые ранние находятся сверху. Записи с неправильной датой помещаются в конец.
- Над таблицей показаны общее количество записей, число просроченных сроков и число сроков в ближайшие 30 дней, включая сегодняшний день.

## 4. Добавление, изменение и удаление

Добавление и редактирование теперь происходят в отдельных окнах с разными заголовками. Выбор строки сам по себе больше не открывает форму редактирования.

Кнопка «Добавить» всегда создаёт новую запись, даже если в таблице выбрано существующее напоминание. Это устраняет прежнюю неоднозначность общей кнопки «Сохранить».

В форме находятся название напоминания, дата и необязательная заметка. Название можно выбрать из списка или написать самостоятельно. Сохранены готовые варианты: страховка, техосмотр, масло в двигателе, масло в коробке и свечи.

Для завершения есть две кнопки: «Сохранить» и «Отмена». Закрытие формы без сохранения не меняет записи. После успешного сохранения соответствующая запись выделяется в таблице.

Открыть выбранную запись можно кнопкой «Изменить» или двойным щелчком по строке. Удаление через корзину требует подтверждения. Удаление не происходит, если пользователь отказался или сохранить изменение не удалось.

## 5. Поле даты и календарь

Вместо трёх отдельных полей дня, месяца и года используется одно поле даты и кнопка со значком календаря.

Дата вводится в виде `25.12.2026`: день, месяц и год разделены точками. Подпись «ДД.ММ.ГГГГ» обозначает именно такой порядок.

В календаре есть русские названия месяцев, неделя с понедельника, переход к предыдущему и следующему месяцу, выделение выбранной даты и кнопка «Сегодня». Количество дней и високосные годы учитываются средствами стандартной библиотеки Python.

При открытии календарь показывает месяц введённой даты. Если поле пустое или дата неправильная, открывается текущий месяц. Выбор дня подставляет дату в форму; сама запись сохраняется только кнопкой «Сохранить».

Несуществующая дата, например 31 февраля, и пустое название не сохраняются. Программа показывает понятное сообщение и возвращает внимание к нужному полю.

## 6. Сроки и обновление дня

Для прошедшей даты показано «Просрочено на … дн.». Для текущей даты — «Срок сегодня». Для будущей даты показано точное число оставшихся дней. Неопределённая надпись «Не скоро» убрана.

Пока программа открыта, она проверяет смену календарного дня каждые 30 секунд. После смены дня обновляются статусы и сводка. Если в этот момент открыта форма редактирования, обновление откладывается до очередной проверки после её закрытия, чтобы не нарушить работу с выбранной записью.

При обновлении сроков выбранная запись сохраняет выделение.

## 8. Сохранение и защита данных

Напоминания по-прежнему хранятся рядом с программой в файле `reminders.json`. JSON — текстовый формат для хранения структурированных данных. У каждой записи остаются поля `kind` (название), `due_date` (дата) и `note` (заметка).

Путь к данным определяется по расположению файла программы, а не по папке, из которой её запустили. Поэтому запуск через ярлык использует тот же файл напоминаний.

Изменения записываются сначала в отдельный временный файл в той же папке. Только после завершения записи и передачи данных на диск программа заменяет основной файл. Временный файл удаляется после операции. Это снижает риск повреждения прежних записей при ошибке сохранения, но не заменяет резервные копии.

Если сохранить данные не удалось, программа показывает ошибку. Изменения не применяются к списку в открытом окне. При добавлении или редактировании форма остаётся открытой с введённым текстом.

Если файл данных повреждён, недоступен или имеет неправильную структуру, программа не подменяет его пустым списком. Она показывает сообщение и отключает добавление записей, чтобы не перезаписать исходные данные. После исправления файла нужно перезапустить программу.

Неправильная дата внутри записи отображается как «Ошибка даты»; такую запись можно открыть и исправить.

Русский текст в программе и данных сохранён в UTF-8 — кодировке, которая поддерживает русские буквы. При проверке исходного файла выяснилось, что прежние искажённые символы были связаны с чтением текста в командной строке, а не с необходимостью менять исходные русские фразы.

В первой строке программы сохранён добавленный комментарий:

```python
#Программа-напоминалка для автомобиля
```

## 9. Управление с клавиатуры

Когда внимание находится на таблице, Enter открывает выбранную запись, Delete вызывает удаление с подтверждением, а Escape снимает выделение.

В форме Enter сохраняет запись, а Escape закрывает форму без сохранения. В календаре Escape закрывает календарь и возвращает к форме.

## 11. Границы текущей версии

Программа проверяет сроки, пока открыто её окно. Уведомления при закрытой программе, автозапуск Windows и фоновая служба не добавлялись. Создание ярлыка на рабочем столе само по себе не включает автозапуск.

В версии на Python пока нет отдельных автомобилей, расчёта обслуживания по пробегу, импорта браузерных записей и экспорта в Excel.

Для работы нужен установленный Python с Tkinter. На текущем компьютере использован Python 3.12. Интернет, сервер и платные подписки для работы этой версии не требуются.

## 12. Где продолжать разработку

В `car_reminder.py` цвета собраны в `COLORS`, оформление задаётся в `apply_theme`, а положение дополнительных окон — в `center_window`.

За главное окно отвечает `CarReminderApp`, за форму — `ReminderDialog`, за календарь — `DatePicker`, за подсказки — `Tooltip`. Это классы: части программы, которые объединяют связанные данные и действия.

Чтение и запись данных находятся в `load_reminders` и `save_reminders`. Расчёт текстового статуса находится в `reminder_status`.
