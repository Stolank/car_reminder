# Журнал работы над напоминалкой

Подробное описание программы, ярлыка, хранения данных и управления находится в [памятке Windows-версии](PROJECT_NOTES_PYTHON.md). Инструкция по сборке и публикации находится в [DEPLOY.md](DEPLOY.md). [План исправлений](FIX_PLAN.md) содержит задачи последней проверки и результаты.

## Что уже сделано

| Этап | Результат |
| --- | --- |
| Главное окно | Список сроков, сводка, отдельные формы добавления и изменения, сортировка, статусы и обновление при смене дня |
| Даты | Ввод день.месяц.год, календарь, проверка даты, управление с клавиатуры |
| Оформление | Светлая тема, цветовые статусы, кнопки по контексту, отдельная иконка для окна и ярлыка |
| Данные | Хранение в JSON, запись во временный файл перед заменой основного, сохранение исходного файла при ошибке чтения |
| Срочные сроки | Фильтр просроченных, ближайших до 30 дней включительно и ошибочных сроков |
| Резервные копии | Экспорт и восстановление с проверкой формата и подтверждением замены, отдельная копия прежнего файла |
| Удаление | Подтверждение и отмена последнего удаления в текущем сеансе |
| Выпуск | Скрипт создания переносимого Windows-архива; данные упакованной версии хранятся отдельно |

## Как версии различаются

- Ярлык на рабочем столе запускает `car_reminder.py`. Исходная версия читает `reminders.json` рядом с программой.
- Переносимая версия использует `%LOCALAPPDATA%\CarReminder\reminders.json`. Перенос между версиями выполняется через меню «Данные».
- `start_reminder.bat` запускает `reminder_easy.html`. Браузер хранит свои данные отдельно. Подробности: [памятка браузерной версии](PROJECT_NOTES_EASY.md).

## Проверки и ограничения

До текущей доработки прошли 20 автоматических тестов настольной версии и проверка браузерной логики. Интерфейс ранее осматривался на вымышленных записях. Запуск предыдущего исполняемого файла заблокировала политика Windows. Публичный выпуск не выполнялся. Проверка автономного запуска и сохранения после перезапуска остаётся в плане выпуска.
