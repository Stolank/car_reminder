# Выпуск Напоминалки

## Windows

Сборка создаёт переносимую программу: на компьютере пользователя отдельная установка Python не нужна. Существующие ярлык и запуск из исходного файла продолжают работать.

На компьютере сборки откройте PowerShell в папке проекта и выполните:

```powershell
python -m pip install --target output/packaging-tools PyInstaller==6.22.3
python -B -m unittest discover -s tests -v
./build-windows.ps1
```

Готовый архив: `output/windows-<дата и время>/CarReminder-Windows.zip`. Распакуйте архив целиком и откройте `CarReminder.exe`. Папка `_internal` рядом с ним нужна для запуска. Сборка включает только код и значок программы; файл с напоминаниями в неё не входит.

Программа из архива хранит записи в `%LOCALAPPDATA%\CarReminder\reminders.json`. Для переноса выберите «Данные → Сохранить копию» в исходной программе, затем в новой версии выберите «Данные → Восстановить из копии». Восстановление заменяет текущий список после подтверждения и сохраняет прежний файл отдельно. Копии браузерной версии не поддерживаются.

Перед публичным выпуском: проверьте запуск на чистой Windows без Python, создание записи и чтение после перезапуска. Для распространения среди других пользователей отдельно решите вопрос цифровой подписи исполняемого файла.

Проверка от 14 ноября 2026 года: архив `output/windows-20261114-220155-044/CarReminder-Windows.zip` успешно распакован. В нём есть `CarReminder.exe`, библиотека Python и файлы Tkinter; личных записей и резервных копий нет. Запуск из распакованного архива с отдельным тестовым профилем и без Python в `PATH` остановила политика управления приложениями Windows. Доступной чистой тестовой среды не найдено. Запуск, сохранение и перезапуск этой сборки не подтверждены.

Проверка на чистой Windows без Python, в тестовом профиле, где запуск сборки разрешён:

1. Распакуйте весь архив и запустите `CarReminder.exe`. Должно открыться главное окно программы.
2. Добавьте запись «Проверка выпуска», выберите дату и введите заметку «Данные после перезапуска». Нажмите «Сохранить».
3. Закройте окно и снова откройте тот же `CarReminder.exe`. Убедитесь, что название, дата и заметка сохранились. При необходимости выключите «Только срочные».
4. Запишите версию Windows и результаты этих трёх проверок. Выпуск считается проверенным только после их успешного прохождения.

## Браузер

`reminder_easy.html` работает самостоятельно; это актуальная браузерная версия. Исторический `index.html` — другая версия. Для статического хостинга разместите **только** актуальный HTML как `index.html` в каталоге публикации. Не выгружайте весь рабочий каталог, архивы проекта или пользовательские файлы данных.

При переходе с локального файла на новый адрес браузер не перенесёт записи автоматически. Сначала сохраните резервную копию из старой версии. Затем импортируйте её на новом адресе. Записи хранятся в браузере, общей базы данных и синхронизации между устройствами нет.

Проверьте добавление записи, перезагрузку страницы и восстановление из копии на новом адресе до публикации ссылки.

## Что улучшать дальше

1. Перепроверить календарь и таблицу при масштабе Windows 150–200% и с экранным диктором. Стрелки календаря реализованы; полный сценарий без мыши в установленной сборке ещё не проверен.
2. Решить, действительно ли нужны уведомления при закрытом окне и синхронизация. Существующие версии их не обеспечивают.

## Проверка удобства

Осмотр выполнен на настольной версии с тестовыми записями.

1. **Главный экран.** Сводка и текстовые статусы помогают различить просроченные и будущие записи даже без цвета. В длинном списке не хватало отдельного просмотра важных сроков. Добавлен переключатель «Только срочные»; сводка при этом считает все записи.
2. **Добавление.** Форма отделена от таблицы, поле даты получает фокус сразу, формат указан в подписи. Значок календаря без текста не всем будет знаком; стоит отдельно проверить, насколько легко его найти с клавиатуры и экранным диктором.

Осмотр не подтверждает полную доступность. Календарь и сохранение проверяются автоматическими тестами; экранный диктор и запуск собранного файла на чистой Windows не проверены.
